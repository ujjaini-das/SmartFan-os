# SmartFan OS

SmartFan OS is an intelligent fan management system designed to
optimize user comfort and reduce unnecessary energy consumption.

## Features

- Temperature monitoring
- Humidity monitoring
- Occupancy detection
- Automatic fan-speed control
- Energy monitoring
- Smart recommendations
- Web-based dashboard

## Technology Stack

### Frontend
- React
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### IoT
- ESP32
- Temperature/Humidity Sensor
- PIR Sensor

## Project Goal

The system dynamically adjusts fan operation based on environmental
conditions and human presence.
